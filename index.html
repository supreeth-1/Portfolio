LSTM Networks for Air Quality Forecasting

Built a time-series forecasting model to predict multiple air pollutants using deep learning techniques. Applied Random Forest Regressor for effective feature selection and trained an LSTM (Long Short-Term Memory) network to capture temporal patterns in environmental data. The model improves prediction accuracy for pollutants like PM2.5 and NO₂, supporting better environmental monitoring and decision-making

Explanaible AI for Gestational Diabetes Risk Prediction

Developed a robust machine learning model to predict gestational diabetes risk using an ensemble of Random Forest and XGBoost, combined with SMOTE-ENN for handling class imbalance. Achieved high accuracy (99.33%) and enhanced model transparency using SHAP, LIME, and counterfactual explanations, enabling better interpretability for healthcare decision support.
